# AcFun 高级弹幕层编辑器（ADL）

> **视频的高级弹幕层编辑器——给视频加一条可发布的字幕/特效轨道，所见即所得，发送只是导出。**

原名 AcFun Danmaku Sender（旧名与旧仓库链接仍指向本项目）。

## 它是给谁做的

- **UP 主本人（第一用户）**：给自己的视频加一条字幕/特效轨道。导入字幕、套特效、彩排、导出，整条主线都为这个场景设计。
- **字幕组**：与 UP 主协调一致后，代为制作并发布字幕层。前提是 UP 主知情同意。
- **野生用户（克制模式）**：在他人视频上使用时，工具会显式提示「这是他人的视频」、收紧发送量并建议先与 UP 主沟通。技术上拦不住无协调写入，但工具不为此优化。

## 它不是什么

- **不是批量发射器**。发送节流、计数显性化、导出前确认是默认约束，不提供「一键倾泻」。
- **不是绕过 UP 主的工具**。不优化「给他人视频无提示写入大量内容」的路径。
- **不与官方高级弹幕面板抢入口**。官方编辑器原样保留，本工具以独立浮层与之共存，各管各的。

## 三分钟上手

<!-- 截图待补：①导入字幕 ②彩排播放 ③导出确认 -->

1. 导入 SRT / ASS / LRC 字幕，轨道上出现字幕行；
2. 选预设、调参数，点「彩排」在视频里完整过一遍；
3. 彩排通过后「导出」解锁，确认并发送。

> **状态注记**：编辑器形态（轨道条 + 独立浮层 + 彩排闸）在重构落地中；当前发布版本仍是「发送器」形态——字幕列表 + 预设 + 预览 + 批量发送，安装方式见下节。预设体系（导入/导出 JSON、参数微调、五阶段特效引擎）保持可用。

## 四道闸（公开承诺）

弹幕发出后**无法撤回**，所以导出之前设四道闸。写在这里，是让使用者与 UP 主都能查验的承诺（随编辑器版本逐步就位）：

1. **彩排闸**：未在视频内完整彩排通过的作品，「导出」不可用；
2. **lint 闸**：导出前逐条校验输出（坐标量级合理（±1000）、时长为正、缓动合法、文本长度上限），不通过则列出病灶、拒绝导出；
3. **计数闸**：始终显示「本作品 = N 条弹幕」，超过阈值需二次确认；
4. **台账闸**：每条发送成功都记录（danmakuId / 内容 / 时间 / 视频），可回查、可引导清理。

## 旧版迁移

旧版（AcFun 弹幕字幕发送器 ≤ 6.5.1）的自定义预设存在浏览器 localStorage（键 `cf_sub_customPresets`、`cf_sub_presetOpt_*` 等），可在旧版「预设面板 → 导出」得到 JSON 文件，再在新版导入。旧脚本请卸载后手动安装新版（本项目无应用商店分发，无自动更新通道）。

## 构建与安装

```bash
npm i                      # 首次：装构建期依赖（esbuild，仅构建用，不影响产物）
npm run build              # 产出 dist/acfun-adl.user.js
npm run check              # 门禁：版本一致 / 禁模式守门 / 引用完整性 / 依赖图（环+可达性）
npm run test               # 冒烟测试（15 组）
npm run gate               # build → check → test 一键串联
```

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)；
2. 新建脚本，将 `dist/acfun-adl.user.js` 的内容粘贴进去保存启用（或直接拖入该文件安装）；
3. 打开 A 站视频页（`www.acfun.cn/v/ac*` 或 `bangumi/aa*`），发送需登录账号。
